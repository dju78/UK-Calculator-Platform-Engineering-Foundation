## Purpose

Work out the monthly saving needed to reach a target by a chosen date.

## Scope

Regular monthly saving into an interest-bearing account, with an optional starting balance.

## Assumptions

- Contributions are made at the END of each month, so a contribution never earns interest before it is paid in.
- A constant interest rate.
- Interest compounds monthly.

## Inputs

| Name | Label | Type | Default | Units / notes |

| `starting_amount` | Starting amount (£) | number | 0 | - |

Percentages are entered as human percentages (5 means 5%) and normalised once
inside the engine.

## Validation

Enforced centrally at the engine boundary and by the shared validation module:

- Any non-finite input is rejected with a readable message.
- Any non-finite output is rejected rather than returned, so `NaN` and
  `Infinity` can never reach a user.
- Terms are bounded (maximum 150 years) and monetary amounts capped, so no
  input can spin an amortisation loop indefinitely.


## Formula and logic

The existing balance grows to `S(1+r)^n`. The remainder is met by an ordinary annuity: `PMT = (target - S(1+r)^n) x r / ((1+r)^n - 1)`. Where the starting balance already exceeds the target, the required saving is zero.
