# UK Calculator Platform — Phase 2 Calculator Content Backfill Plan

## Overview
This document establishes the editorial strategy, structural guidelines, and prioritized rollout plan for authoring bespoke, professional explanatory content across the top 40 high-value UK calculators in Phase 2.

## 1. Editorial Guidelines & Structural Standards
Every prioritized calculator page will be enhanced with a standardized, accessible content layout beneath the interactive calculator tool:

- **Standard Modular Structure:**
  1. **Executive Overview & Practical Purpose** (100-150 words)
  2. **Step-by-Step Calculation Methodology & Mathematical Formula** (150-200 words)
  3. **Concrete UK Worked Example** (with realistic 2026/27 figures)
  4. **Key Assumptions & Statutory Boundary Conditions**
  5. **Official Regulatory / Industry Citations** (GOV.UK, HMRC, BoE, FCA)
  6. **Related Calculators & Next Steps**
  7. **Frequently Asked Questions (FAQs)** (3-5 common practical questions)

## 3. Implementation Workflow for Phase 2

1. **Guide Component Layout:**
   - Develop a modular, accessible <CalculatorGuide> layout component supporting clear editorial sections, callout boxes, worked examples, and accessible accordion FAQs.
2. **Review & Regulatory Verification:**
   - Verify all statutory thresholds and rules against published UK legislation, HMRC manuals, and devolved administration guidance.
3. **Appropriate Structured Data Implementation:**
   - Implement genuine schema matching actual page content:
     - WebApplication / SoftwareApplication for interactive tool functionality.
     - BreadcrumbList for category and navigation hierarchy.
     - FAQPage strictly where genuine, comprehensive FAQ accordions are authored on the page.
     - HowTo strictly where step-by-step procedural guides are present.
   - *Note:* Do NOT apply FinancialProduct schema to calculator pages; calculators are software tools, not financial products. Schema must reflect actual page content rather than being mass-applied for search engine gaming.
